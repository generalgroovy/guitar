# Guitar Practice Generator

For ongoing guitar and bass practice, use **[ToneDef](https://generalgroovy.github.io/tonedef/)**
([source](https://github.com/generalgroovy/tonedef)). ToneDef is the main application;
this earlier single-page generator is preserved as a reference.

ToneDef brings the ascending, descending and arch melody concepts into its
configurable fretboard and practice generator, alongside editable patterns,
playback, saved projects and portable Markdown practice cards.

The original `index.html` remains available here. Existing browser data is not
automatically transferred between the applications.
